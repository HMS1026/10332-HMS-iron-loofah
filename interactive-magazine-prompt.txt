너는 초·중등 과학 교육 콘텐츠를 만드는 편집자이자 웹 개발자야.
첨부한 허민서의 「철수세미 주제 탐구 보고서: 테트라포드의 원리 분석을 통한 헥사포드와의 소파 효과 비교」와 기존 인터랙티브 잡지 「파도의 사이」를 바탕으로, 직접 조작하며 배우는 교육용 웹 잡지를 완성해 줘.

가장 중요한 요청
PDF, 정적인 슬라이드, 잡지 모양의 이미지로 바꾸지 마. 기존 웹 잡지의 모형 회전, 수조 흔들기, 조건 조절, 기록, 그래프 전환, 개념 애니메이션을 유지하고, 내용을 초등학교 3학년부터 중학생까지 이해할 수 있게 바꿔 줘. 결과는 실제로 열어 사용할 수 있는 인터랙티브 웹페이지로 제공해 줘.

1. 독자와 교육 목표
- 초등 독자는 쉬운 말과 조작 활동으로 원리를 배우고, 중등 독자는 변인 통제와 실험의 한계까지 생각할 수 있게 해 줘.
- 화면 위에 ‘쉽게 읽기 · 초등’과 ‘더 알아보기 · 중등’ 선택 버튼을 만들어 줘. 처음에는 쉽게 읽기를 보여 줘.
- 초등 모드에서는 짧은 설명과 기본 조작을 먼저 보여 줘. 중등 모드에서는 추가 원리 설명과 상세 조절 항목을 펼쳐 줘.
- 숨겨진 설명은 초등 모드에서도 ‘더 알아보기’를 눌러 직접 펼칠 수 있게 해 줘.
- 모든 모드에서 실제 관찰값, 가상 계산값, 설명 그림의 구분을 유지해 줘.
- ‘먼저 예상하기 → 직접 조작하기 → 관찰하기 → 다시 생각하기’ 순서로 배우게 해 줘.

2. 문장과 설명 방식
- 친근한 ‘~해요’, ‘~일까요?’ 말투를 사용해 줘. 한 문장에 한 가지 생각을 담고, 한 문단은 2~3문장으로 짧게 써 줘.
- 전문용어는 쉬운 뜻과 함께 소개해 줘.
  방파제: 바다에서 오는 파도의 영향을 줄이려고 만든 시설.
  소파: 파도의 작용을 줄이는 것.
  월파: 파도가 방파제 위를 넘어오는 현상.
  공극률: 쌓아 놓은 전체 공간에서 빈틈이 차지하는 비율.
  와류: 물이 빙글빙글 돌며 흐르는 현상.
  변인 통제: 비교할 것 외의 조건을 되도록 같게 맞추는 것.
- ‘공극률을 조정하세요’보다 ‘빈틈 비율을 바꿔 보세요’, ‘주기를 설정하세요’보다 ‘한 번 왕복하는 시간을 바꿔 보세요’처럼 행동이 보이는 문구를 써 줘.
- 어린이에게 모든 조건을 한 번에 바꾸도록 권하지 말고, 한 가지씩 바꾸며 비교하게 안내해 줘.

3. 원본에서 확인된 탐구 사실
- 테트라포드 모형 8개, 헥사포드 모형 8개를 비교했어.
- 모형 크기는 각각 4×4 cm와 3.8×3.8 cm로 적혀 있어. 크기나 질량이 완전히 같았다고 쓰지 마.
- 처음에는 방수 처리한 상자에서 아크릴판 뒤에 물을 모았다가 판을 빼서 파도를 만들려고 했어.
- 물이 새는 문제 때문에 투명 수조와 어린이용 자동차를 이용해 수조를 움직이는 방법으로 바꿨어.
- 수조를 좌우로 왕복 5회 움직이고 모눈종이의 젖은 칸 수를 비교했어. 왕복 5회는 실험 반복 횟수가 아니야.
- 기본 배치와 구조물을 지반에서 3 cm 떨어뜨린 배치를 비교했어. 높이를 3 cm 올렸다고 표현하지 마.
- 관찰 결과의 대략적인 대표값:
  기본 배치: 테트라포드 약 10칸, 헥사포드 약 8칸.
  3 cm 떨어뜨린 배치: 테트라포드 약 14칸, 헥사포드 약 4칸.
- 공극률과 와류를 직접 측정하지 않았어.
- 흔드는 세기 등 조건을 완전히 같게 통제하기 어려웠어.
- 반복 실험의 개별 원자료나 통계적 오차 범위를 새로 만들어 넣지 마.

4. 잡지의 구성과 상호작용

A. 표지와 읽기 수준 선택
- 기존 제목 ‘파도의 사이’를 유지해 줘.
- 큰 표지 제목은 ‘출렁출렁! 파도를 막는 특별한 발.’로 써 줘.
- 부제는 ‘네 발과 여섯 발, 무엇이 다를까요? 돌려 보고, 흔들어 보고, 직접 발견해요.’로 써 줘.
- 표지의 움직이는 모형과 물결 표현, 목차, 읽기 진행 표시를 유지해 줘.
- ‘직접 수조 흔들어 보기’를 누르면 수조 체험으로 이동하게 해 줘.

B. 모형을 돌려 보는 활동
- 테트라포드와 헥사포드를 손가락이나 마우스로 좌우 회전할 수 있게 해 줘.
- 키보드 좌우 방향키도 지원해 줘.
- ‘뒤에 숨은 발도 찾아보세요’ 같은 관찰 미션을 넣어 줘.
- 입체 모형은 실제 치수를 정확히 복원한 것이 아닌 설명용 그림임을 짧게 밝혀 줘.
- 아래에는 보고서의 실제 모형 사진을 나란히 넣고 크게 볼 수 있게 해 줘.

C. 사진으로 보는 실제 탐구 과정
- ‘앗, 물이 새요! 방법을 바꿔 볼까?’라는 제목으로 첫 실패를 소개해 줘.
- 처음 만든 상자와 바꾼 투명 수조 사진을 비교해서 보여 줘.
- ‘물이 샜어요 → 방법을 바꾸었어요 → 수조를 움직였어요 → 종이의 흔적을 비교했어요’라는 이야기를 짧게 구성해 줘.
- 실패를 감추거나 실험을 잘못했다고 단정하지 말고 다음 방법을 찾는 계기로 설명해 줘.
- 왕복 5회의 뜻을 별도 작은 설명으로 넣어 줘.

D. 직접 조작하는 가상 수조
- 기존의 물 움직임 계산과 수조 조작 기능을 유지해 줘. 단순 반복 동영상으로 대체하지 마.
- 수조 드래그, 키보드 흔들기, 자동 흔들기, 일시정지, 초기화를 제공해 줘.
- 기본 화면에는 구조물 선택, 배치 선택, 흔드는 세기를 보여 줘.
- ‘더 조절해 보기’를 열면 왕복 시간과 빈틈 비율을 조절할 수 있게 해 줘.
- 조건을 바꾸면 처음부터 다시 시작한다는 안내를 넣어 줘.
- ‘약하게 흔들기’, ‘세게 흔들기’, ‘위치 바꿔 보기’ 미션 버튼을 만들어 줘.
- 세기 비교에서는 모형, 위치, 왕복 시간, 빈틈 비율을 동일하게 맞추고 세기만 바꿔 줘. 예를 들어 35%와 75%를 비교해 줘.
- 위치 비교에서는 세기 35%, 왕복 시간 1.4초, 빈틈 비율 50%를 유지하고 위치만 바꿔 줘.
- 비교할 때 같은 시간 동안 관찰하라고 안내해 줘.
- 가상 체험의 경과 시간, 수면 변화, 넘어간 물의 계산값을 보여 주되 ‘가상 계산값’을 눈에 띄게 표시해 줘.
- 현재 조건과 결과를 관찰 노트에 기록하고 CSV로 받을 수 있게 해 줘. 새로고침 후 보존 여부도 실제 동작에 맞게 안내해 줘.
- 아직 시작하지 않았다면 빈 기록을 남기지 말고 먼저 흔들어 보라고 안내해 줘.
- 실제 모형별 저항을 검증한 자료가 없다면 헥사포드가 무조건 좋게 나오도록 계산하지 마. 같은 공극률에서 같은 저항을 적용한다는 기존 한계를 유지해 줘.
- 이 체험은 모양별 성능을 예측하는 도구가 아니라 물 움직임을 이해하는 교육용 모형이라고 알려 줘.
- 개별 발 주변 3차원 와류, 물보라, 실제 충격력 등을 계산한 것처럼 표시하지 마.

E. 예상과 실제 결과 비교
- ‘3 cm 떨어뜨리면 두 모형 모두 종이가 덜 젖을까요?’라고 먼저 물어봐 줘.
- ‘둘 다 덜 젖을 것 같아요’와 ‘서로 다를 수도 있어요’ 중 선택하게 하고, 예상 자체를 정답·오답으로 벌점 주지 마.
- ‘기본 배치’와 ‘3 cm 떨어뜨리기’ 버튼에 따라 막대그래프가 바뀌게 해 줘.
- 기본값 10·8, 떨어뜨린 배치 14·4를 정확히 표시해 줘. 단위는 ‘젖은 칸 수’로 써 줘.
- 두 상태에 같은 막대 축척을 사용하고 0에서 시작하게 해 줘. 실제 물의 양이나 에너지 감소율로 환산하지 마.
- 결과를 선택하면 쉬운 해설도 함께 바뀌게 해 줘.
  기본: ‘헥사포드 쪽이 약 2칸 덜 젖었어요.’
  떨어뜨린 배치: ‘테트라포드는 약 4칸 더 젖고, 헥사포드는 약 4칸 덜 젖었어요.’
- ‘멀리 놓는다고 항상 덜 젖는 것은 아니었어요’라고 정리해 줘.
- 사진에서 젖은 칸 수를 자동 판독했다고 주장하지 마. 수치는 보고서의 기록을 사용해 줘.

F. 만지며 배우는 과학 낱말
- 공극률은 100칸 그림과 슬라이더로 보여 줘. 빈틈 비율 30%면 100칸 중 30칸이 빈틈으로 표시되게 해 줘.
- 이 그림은 설명용이며 실제 모형의 측정 결과가 아님을 밝혀 줘.
- 와류는 장애물 주변에서 점들이 돌아 흐르는 설명 애니메이션으로 보여 줘. 재생·멈춤을 제공해 줘.
- 실제 관찰 영상이나 가상 수조의 와류 계산 결과처럼 소개하지 마.
- 빈틈이나 소용돌이가 많으면 무조건 소파 효과가 좋아진다고 말하지 마.
- 공극률과 와류는 이번 실험에서 직접 재지 않았으므로 결과의 원인은 추가 확인이 필요하다고 써 줘.

G. 생각 확인 퀴즈
- 기존 결론 퀴즈를 쉬운 문장으로 유지해 줘.
  정답: ‘이번 수조에서 모양과 배치에 따른 차이를 관찰했어요.’
  오답: ‘헥사포드는 모든 바다에서 더 좋아요.’ / ‘발의 개수만 알면 넘어오는 물의 양을 알 수 있어요.’
- 추가 문제 1: 직접 비교한 것은? 정답 ‘모눈종이의 젖은 칸 수’, 오답 ‘만들어진 전기의 양’.
- 추가 문제 2: 왕복 5회의 뜻은? 정답 ‘수조를 갔다가 돌아오게 다섯 번 움직였어요’, 오답 ‘실험을 다섯 번 반복했어요’.
- 답을 누를 때마다 이유를 쉬운 말로 설명하고, 다시 선택할 수 있게 해 줘.
- 추가 두 문제는 맞힌 개수를 보여 주고 ‘다시 풀기’를 제공해 줘. 정답을 여러 번 눌러 점수가 중복 증가하지 않게 해 줘.

H. 다음 탐구와 제작 프롬프트
- 자연환경 자료와 컴퓨터 실험은 ‘앞으로 해 볼 탐구’로 구분해 줘. 실제로 완료하지 않은 성과를 만들지 마.
- 화면 아래 ‘전체 제작 프롬프트’ 버튼을 만들어 이 프롬프트 전문을 읽고 복사하거나 텍스트로 내려받을 수 있게 해 줘.
- 복사 기능이 제한되면 텍스트 선택이나 다운로드로 이어지게 해 줘.

5. 실제 사진 사용 규칙
- 원본 보고서의 사진을 추출해 넣어 줘. 생성형 이미지로 실험 장면을 새로 만들지 마.
- 학생의 직접 실험 사진과 참고 이미지를 구분하고, 실제 장면을 확인한 뒤 설명을 달아 줘.
- 실제 사진 8장 정도를 모형 소개, 실패와 개선, 결과 비교에 나누어 넣어 줘.
- 사진을 누르면 확대 화면과 설명이 열리고, 닫기 버튼이나 Escape로 돌아올 수 있게 해 줘.
- 사진의 모형 수, 위치, 물결, 젖은 흔적을 바꾸지 마. 찌그러뜨리거나 중요한 장치를 잘라내지 마.
- 모바일에서는 적절한 크기의 최적화된 사진을 불러오고 원래 비율을 유지해 줘.
- 사진에 보이지 않는 와류나 누수 위치를 실제 관찰한 것처럼 화살표로 만들어 넣지 마.
- 사진만으로 조건을 특정하기 어려우면 일반적인 장면 설명을 사용해 줘.
- 자료와 사진 출처를 잡지 하단에 밝혀 줘.
- 원본 HWP 이미지 식별자를 사용할 수 있으면 다음 배치를 참고해 줘.
  BIN0001·BIN0002: 실제 모형 소개.
  BIN0003·BIN0005: 처음 장치와 방법을 바꾼 수조.
  BIN0006·BIN000A: 수조와 배치 사진 추가 보기.
  BIN0007·BIN0009: 모눈종이 흔적과 배치 관찰.
  이 식별자는 원본 파일 내부 이름이며 보고서의 쪽 번호는 아니야.

6. 디자인과 접근성
- 기존 「파도의 사이」의 바다색·민트색, 큰 제목, 잡지다운 여백과 구성을 이어가 줘.
- 본문은 최소 16px, 주요 조작 설명과 버튼은 14px 이상을 기본으로 해 줘.
- 어린이가 버튼과 슬라이더의 역할을 바로 알 수 있게 눈에 보이는 이름을 붙여 줘.
- 휴대폰에서는 한 열 중심으로 배치하고 버튼을 누르기 쉽게 만들어 줘.
- 키보드 포커스, 방향키 조작, 대화상자 닫기, 스크린리더용 이름, 상태 변화 안내를 지원해 줘.
- 움직임 줄이기 설정을 존중하고 불필요한 자동 움직임을 줄여 줘.
- 색만으로 의미를 전달하지 말고 숫자와 설명도 함께 표시해 줘.
- 교육 내용과 조작을 중심으로 보여 주고 개발 도구나 제작 절차를 학습 흐름에 섞지 마.

7. 과학적 정확성
- 젖은 칸 수와 물의 부피, 가상 계산값과 실측값을 섞지 마.
- 파도 에너지가 ‘파괴된다’고 쓰지 마.
- 한 번의 예측과 관찰이 다르다는 이유만으로 실험이 틀렸다고 단정하지 마.
- 실험 결과만으로 원인을 확정하거나 모든 실제 바다에 일반화하지 마.
- 아직 관찰하거나 계산하지 않은 공극률, 와류 세기, 충격력, 발전량을 만들어 넣지 마.

8. 완성과 검증
- 원래 웹사이트가 확인되면 그 사이트를 수정해 같은 주소로 제공해 줘. 접근 권한과 공개 범위를 임의로 바꾸지 마.
- 개요나 코드 일부만 제시하지 말고 실제로 쓸 수 있는 완성된 웹 잡지를 만들어 줘.
- 모형 회전, 수조 자동/수동 조작, 일시정지, 초기화, 조건 변경, 관찰 기록, CSV, 결과 전환, 사진 확대/닫기, 읽기 수준 전환, 빈틈 슬라이더, 퀴즈 재시도, 프롬프트 표시/복사를 점검해 줘.
- 페이지가 가로로 넘치거나 사진·텍스트·버튼이 겹치지 않는지 확인해 줘.
- 계산을 바꾸지 않았다면 기존 물리 모형의 한계를 그대로 설명하고, 새 교육 기능이 이를 과장하지 않는지 확인해 줘.
- 마지막 답변에는 완성된 인터랙티브 잡지 링크와 주요 변경 사항만 간단히 알려 줘. PDF를 제공하지 마.
