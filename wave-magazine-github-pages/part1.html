방법을 바꾼 순간

투명한 수조와 어린이용 자동차를 이용했어요. 수조를 좌우로 움직여 물결을 만들었어요. 실패도 다음 방법을 찾는 힌트가 되었지요.

실제 수조 사진 더 보기

실제로는 이렇게 비교했어요

  1. 두 종류의 모형을 각각 8개씩 준비했어요.
  2. 수조를 왕복 5회 움직였어요.
  3. 모눈종이의 젖은 칸 수를 살펴봤어요.
  4. 모형을 지반에서 3 cm 떨어뜨린 배치도 비교했어요.

왕복 5회는 갔다가 돌아오는 움직임을 다섯 번 했다는 뜻이에요. 실험을 다섯 번 반복했다는 뜻은 아니에요.

비교할 것 외의 조건을 되도록 같게 맞추는 것을 ‘변인 통제’라고 해요. 이번 탐구에서는 흔드는 세기 등을 완전히 같게 맞추기 어려웠어요. 다음에는 물 높이, 움직이는 속도와 거리도 일정하게 맞춰 보면 좋아요.

가상 체험과 실제 실험은 어떻게 다를까요?

쉽게 말하면: 컴퓨터가 물의 높이와 움직임을 간단히 계산해 보여 주는 체험이에요. 실제 모형의 발 주변 흐름까지 똑같이 재현하지는 않아요. 같은 빈틈 비율이면 두 모양에 같은 저항을 주기 때문에, 모양만 바꿔서는 차이가 나지 않아요.

중등 탐구자를 위한 계산 설명

물의 깊이와 수평 유속을 시간에 따라 계산하는 1차원 천수 유동 모형입니다. 흔들림에 의한 관성력, 중력, 바닥 형상, 반사, 저항, 방파제 위를 지나는 물의 흐름을 단순화해 표현합니다. 물의 움직임을 계산하지만 개별 발 주변의 3차원 와류나 물보라는 해석하지 않습니다.

테트라포드와 헥사포드는 실제 형상·실측 저항 자료가 없으므로 같은 공극률에서는 동일한 저항을 적용합니다. 모양만 바꿔도 헥사포드가 더 좋도록 결과를 미리 정해 놓지 않았습니다. 위치와 공극률을 바꾸며 가설을 탐색해 보세요.

가상 치수: 수조 길이 120 cm, 폭 20 cm, 초기 수심 12 cm, 방파제 마루 높이 15.5 cm. 표시 부피는 마루를 육지 쪽으로 통과한 양을 누적한 값으로, 되돌아온 뒤 다시 넘어간 물은 재집계될 수 있습니다. 실제 수조 치수·실험값에 맞춰 보정하지 않았습니다. 아래 실제 관찰 기록의 젖은 칸 수와 직접 환산할 수 없습니다.

POROSITY

공극률 = 빈틈이 차지하는 비율

모형을 쌓으면 사이사이에 빈틈이 생겨요. 전체 공간에서 빈틈이 얼마나 되는지를 나타내는 말이 공극률이에요. 아래 막대를 움직여 보세요.

민트색은 빈틈, 회색은 구조물이에요. 100칸으로 쉽게 나타낸 설명 그림이며, 실제 모형을 측정한 결과는 아니에요.

빈틈이 많다고 항상 더 좋은 것은 아니에요. 물이 어떻게 지나가는지, 모형이 얼마나 튼튼하게 놓여 있는지도 살펴봐야 해요.

VORTEX

와류 = 빙글빙글 도는 물의 흐름

물이 장애물을 지나며 빙글빙글 돌 수도 있어요. 이런 회전하는 흐름을 와류라고 해요. 점들이 움직이는 방향을 살펴보세요.

와류를 이해하기 위한 설명 그림이에요. 실제 실험 영상이나 수조의 계산 결과는 아니에요.

물이 돌아 흐른다고 파도가 얼마나 약해졌는지 바로 알 수는 없어요. 물의 움직임과 파도의 변화를 함께 살펴봐야 해요.
