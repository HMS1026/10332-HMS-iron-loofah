# 파도의 사이 인터랙티브 과학 잡지

1부 실제 수조 실험과 2부 파도 에너지 시뮬레이션을 연결한 웹 잡지입니다.

## GitHub Pages에 올리기

1. 이 ZIP 파일을 컴퓨터에서 압축 해제합니다.
2. GitHub에서 wave-magazine이라는 새 저장소를 만들고 Public을 선택합니다. Add README를 켜도 됩니다.
3. Add file → Upload files로 이동합니다.
4. 압축 해제한 폴더 안의 파일과 하위 폴더를 모두 끌어다 놓습니다. ZIP 파일 자체나 바깥 폴더 하나를 올리지 않습니다.
5. 변경 사항을 main 브랜치에 저장합니다.
6. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save를 선택합니다.
7. 배포가 끝나면 같은 Pages 화면에 표시되는 Visit site 주소를 엽니다.

저장소 첫 화면에 index.html, part1.html, part2.html과 photos, part2-assets 폴더가 보여야 합니다.
사진 폴더를 따로 올릴 때도 원래 폴더 이름과 구조를 유지합니다.
공개 저장소에 올린 사진, 글, 코드와 GitHub Pages 잡지는 누구나 볼 수 있습니다.

## 확인하기

- 첫 화면의 1부와 2부 선택
- 실제 사진과 이미지 확대
- 1부 모형 회전과 수조 조작
- 2부 공극률 변경, 에너지 비교, 미션, 회전 탐정, 퀴즈

별도의 Python 설치나 서버 실행은 필요하지 않습니다. 잡지에 연결된 외부 Streamlit 프로그램은 별도 서비스입니다.
구글 웹폰트에 접속할 수 없으면 기기의 기본 글꼴을 사용합니다.
